# Contact Form

A clean, modern, and responsive contact form built as part of my Front-End Web Development Internship at Elevvo.

### Features
- Full Name, Email Address, Subject, and Message fields.
- JavaScript form validation.
- Required field validation.
- Email format validation.
- Success message after valid submission.
- Responsive design for mobile and desktop screens.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Project Structure
- `index.html` – Form structure.
- `style.css` – Styling and responsive design.
- `script.js` – Form validation and functionality.

### Note
This is a front-end project. Form submissions are validated locally and are not sent to an actual email address or backend.
